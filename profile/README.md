# Level73

**Ethical digital infrastructure built around people.**

We design, build and maintain websites, platforms, data systems and web applications for organisations, networks and non-profits.

We believe technology should reduce complexity instead of creating it. That applies to the systems people interact with, but also to the code, dependencies and infrastructure behind them.

## How we build

We tend to favour:

- understandable architectures over unnecessary abstraction;
- open standards and interoperable data;
- progressive enhancement and semantic HTML;
- small dependency trees where possible;
- established technologies when they solve the problem well;
- accessibility and privacy as architectural concerns;
- systems that can be maintained by people other than their original authors.

Technology choices are contextual. We use the tools that fit the organisation, the existing infrastructure and the problem being solved rather than imposing a predetermined stack.

## What you will find here

Most of our work lives in long-running organisational systems and is not publicly accessible or suitable for release as open source.

The repositories here include open-source components, project-specific code we can share, data visualisation work, experiments and tools developed along the way.

Some are current. Others remain public because they document earlier projects and parts of Level73's technical history.
